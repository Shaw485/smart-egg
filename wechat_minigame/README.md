# 怪奇之原 · 微信小游戏版（v163）

这是与网页/Android 版本隔离的微信小游戏工程，复用 v159 的七个主线关卡、创造模式、关卡码、F4 UI、物理与绘制逻辑。

## 导入微信开发者工具

1. 打开微信开发者工具，选择“小游戏”。
2. 导入本目录 `wechat_minigame`。
3. 当前工程已配置为本机微信开发者工具中的小游戏测试号，可直接编译调试。
4. 预览、真机调试或上传正式版本前，将 `project.config.json` 的 `appid` 替换为正式小游戏 AppID。
5. 在工具中选择横屏设备，点击“编译”。

> v162 已兼容微信基础库 3.17.x 的只读 `Window` 全局属性。若开发者工具冷启动出现一次 `routeTo appLaunch timeout`，但模拟器随后正常显示关卡，这是工具启动握手超时，不是游戏运行错误；再次点击“编译”即可继续调试。

> v163 在微信开发者工具中新增实体键盘控制：`A` 左移、`D` 右移、`空格` 跳跃，支持按住移动键时同时跳跃。

## 首轮真机验收

- 首页、主线选关页和 1–7 关均能进入。
- 左右移动与跳跃支持多指同时按住。
- 第 4 关二段跳、第 5 关敲门、第 6 关花朵密码、第 7 关按住逃跑门正常。
- 创造模式能保存、删除、试玩自定义关卡。
- 关卡码可以复制，点击“输入关卡码”会拉起微信键盘。
- 首次触摸后能播放背景音乐、跳跃、解锁、敲门和通关音效。
- 首页右上角日志按钮可以写入并分享/复制诊断日志。

## 结构

- `game.js`：微信小游戏入口。
- `js/wechat-adapter.js`：微信 API 兼容层。
- `js/levels.js`：内嵌七关数据，不走网络请求。
- `js/smart-egg-game.js`：由主游戏 v159 复制并仅做微信入口适配。
- `assets/tone-*.wav`：不支持 WebAudio 时的程序化音乐兼容音源。
- `tests/smoke-test.js`：Node.js 启动冒烟测试。
