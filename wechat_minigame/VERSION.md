# 微信小游戏版本记录

## v163 · 2026-08-27

- 微信开发者工具中支持 `A` 左移、`D` 右移、`空格` 跳跃。
- 实体键盘事件由微信宿主 Window、document 与原生显示画布只读转发到游戏隔离环境，不覆盖开发者工具的原生事件方法。
- 支持按住 `A`/`D` 移动时同时按空格跳跃，松开空格不会中断横向移动。
- 冒烟测试增加宿主实体键盘转发与组合按键回归。

## v162 · 2026-08-27

- 修复微信基础库 3.17.x 把 `GameGlobal` 实现为只读 `Window` 后，适配层覆盖 `window`、`globalThis`、`document` 等属性导致的启动黑屏。
- 新增独立的 `__SMART_EGG_WECHAT_ENV__`，游戏本体从兼容环境读取浏览器接口，不再修改微信宿主的只读对象。
- 修复冻结 `navigator` 与只读视口属性的兼容问题，并隔离游戏弹窗，避免干扰开发者工具的主包加载握手。
- 冒烟测试新增只读全局、冻结对象、首帧绘制、七关载入和 10 项输入回归覆盖。
- 已在微信开发者工具 Stable 2.02.2608060、基础库 3.17.1/3.17.x 模拟器中验证第一关正常渲染。

## v161 · 2026-08-27

- 开启微信开发者工具服务端口，支持 CLI 与后续自动化调试。
- 将工程切换到当前开发者工具中可用的小游戏测试号 AppID。
- 验证微信开发者工具可以通过命令行成功载入工程。

## v160 · 2026-08-26

- 建立独立 `wechat_minigame` 工程，不修改网页 v159 与 Android APK。
- 复用七个主线关卡、创造模式、关卡码、详细日志、F4 UI 与全部游戏机制。
- 接入微信小游戏横屏 Canvas、刘海安全区与 1920×1080 等比例渲染。
- 接入多点触控，支持移动与跳跃同时按下。
- 接入微信本地存储、剪贴板、系统键盘、生命周期和错误事件。
- 优先使用微信 WebAudio；不支持时使用 InnerAudioContext 音源兼容背景音乐与音效。
- 日志导出改为写入微信用户目录，并在能力允许时分享，否则复制到剪贴板。
- 内嵌七关数据，不依赖本地 JSON fetch 或业务服务器。
- 增加启动冒烟测试与 10 项输入回归测试。
