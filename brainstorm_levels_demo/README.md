# 第 8–12 关脑洞玩法试玩

这是保留的独立机制试玩目录。v2 起，同组机制已作为正式第 8–12 关接入 `web_preview` 网页主线；v3 修复第 8 关双太阳和影子显示；v4 将顶部按钮改为矢量图标并移除右侧关卡列。本目录仍用于单关对照和机制调试。Android APK 与微信小游戏工程本次暂未同步。

## 关卡

- 第 8 关「日影无声」：拖动光源，让影子触发机关。
- 第 9 关「等风来」：停止操作后观察变化。
- 第 10 关「纸上有路」：把标题中的元素用于场景。
- 第 11 关「痕迹未散」：重来时保留部分场景状态。
- 第 12 关「远方未远」：直接拖动画面中的世界。

标题只保持主题关联，不直接公布答案。具体线索仅在关卡内的 `?` 提示按钮显示。

## 操作

- 键盘：`A` / `D` 移动，空格跳跃，`R` 重来。
- 触屏/鼠标：使用底部按钮；拖动太阳、标题文字或背景完成特殊操作。
- 通关后点击“下一关”依次体验第 8–12 关；开发调试时仍可在控制台按编号切换。

## 诊断日志

页面右上角“诊断日志”可下载本次试玩的 JSON 日志。日志按模块记录：

- `runtime`：启动、音频、异常和日志导出。
- `state`：进入、重来、提示和通关状态。
- `input`：键盘、触摸/鼠标、失焦清理。
- `mechanic`：光源、静止、拖字、重来保留、拖地图等机关状态。
- `render`：尺寸变化和绘制异常。

可在控制台执行以下命令独立调试：

```js
__brainstormDemo.getState()
__brainstormDemo.enterLevelById(10)
__brainstormDemo.logs.setModule('input', false)
__brainstormDemo.logs.setLevel('debug')
__brainstormDemo.logs.snapshot()
```

日志最多保留 900 条，敏感字段会自动脱敏；本试玩没有服务端请求。
