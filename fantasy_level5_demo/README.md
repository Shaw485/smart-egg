# 第五关原创奇幻视觉试验

这是与现有 Smart Egg 游戏完全隔离的独立页面，只用于比较美术方向。

- 保留第五关“靠近目标门后敲门两次”的核心玩法。
- 采用原创日式赛璐璐奇幻冒险视觉，不包含塞尔达角色、名称、Logo、地图、音乐或游戏素材。
- 直接打开 `index.html`，或通过项目根目录 HTTP 服务访问本文件夹即可试玩。
- 本目录不被现有游戏入口、Android APK 或构建脚本引用，不会影响当前版本。

## 主线文案方向（后续统一采用）

- 每关使用“地点短标题 + 带一点世界观的任务句”，保留谜题感但不直接剧透。
- 示例语气：`风之遗迹／以礼叩响古门`、`林海高塔／登阶，回应沉睡的守望者`。
- 名称、世界观、台词和配乐全部保持原创，不复用商业游戏的专有内容。
